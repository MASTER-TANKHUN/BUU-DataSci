มี Average Views สูงกว่า?

กราฟต้นฉบับเปรียบเทียบ average view count ตามวันในสัปดาห์ โดยวันพุธอยู่สูงที่สุด

Key read
≈ 1.1M

Wednesday อยู่ลำดับ #1 ในกราฟ; Friday และ Thursday ตามมา

Average views by published day
ความยาวแท่งใช้ relative index จากกราฟต้นฉบับ โดย Wednesday = 100
สรุป

จากกราฟ วันพุธเป็นวันที่วิดีโอที่เผยแพร่มี average views สูงที่สุด โดยอยู่ที่ประมาณ 1.1 ล้าน views. ส่วน Saturday อยู่ต่ำที่สุดในกราฟที่แนบ

สมมติฐานในการตีความ

ทีมตั้งสมมติฐานว่า ช่วงเสาร์–อาทิตย์ผู้ชมบางส่วนอาจเลือกฟังรายการสดเพราะมีเวลาว่าง ส่วนวันพุธซึ่งอยู่กลางสัปดาห์อาจเป็นช่วงที่ผู้ชมกลับมาดูย้อนหลังบน YouTube มากขึ้น

กราฟนี้ยังไม่สามารถพิสูจน์สมมติฐานดังกล่าวได้ เพราะไม่ได้วัดพฤติกรรมการฟังสดหรือควบคุมอายุคลิป/ประเภทคลิป

วิธีอ่านกราฟ

Bar chart เหมาะกับการเปรียบเทียบ 7 วัน เพราะความยาวแท่งอ่านอันดับได้ทันที และสามารถ Filter แยก Weekday / Weekend ได้

  • Wednesday = อันดับ 1
  • Friday = อันดับ 2
  • Thursday = อันดับ 3
  • Saturday = อันดับสุดท้าย

ข้อจำกัด

Final.zip มีภาพกราฟแต่ notebook ของ Day-of-Week เป็นไฟล์ว่าง จึงไม่ควรสร้างค่าตัวเลข exact ของทุกวันขึ้นมาใหม่จากไม่มีหลักฐาน. หน้าเว็บจึงเก็บตัวเลข ≈1.1M เฉพาะ Wednesday ตามการอ่านกราฟ และใช้ relative index สำหรับการเปรียบเทียบทั้ง 7 วัน
