มี Average Views สูงกว่า?

วิเคราะห์ค่าเฉลี่ยของ view_count ตามวันเผยแพร่ในสัปดาห์ แล้วเรียงจากมากไปน้อย โดยวันพุธมีค่าเฉลี่ยสูงที่สุด

สรุป

เมื่อคำนวณ Average View Count แยกตามวันเผยแพร่ พบว่า Wednesday อยู่ลำดับสูงที่สุดที่ 1,087,180.09 views ต่อคลิป ตามด้วย Friday และ Thursday ขณะที่ Saturday อยู่ลำดับต่ำที่สุด

สมมติฐานในการตีความ

ทีมตั้งสมมติฐานว่า ช่วงเสาร์–อาทิตย์ผู้ชมบางส่วนอาจเลือกฟังรายการสดเพราะมีเวลาว่าง ส่วนวันพุธซึ่งอยู่กลางสัปดาห์อาจเป็นช่วงที่ผู้ชมกลับมาดูย้อนหลังบน YouTube มากขึ้น

กราฟนี้ยังไม่สามารถพิสูจน์สมมติฐานดังกล่าวได้ เพราะไม่ได้วัดพฤติกรรมการฟังสดหรือควบคุมอายุคลิป/ประเภทคลิป
PROCESS

จากวันที่เผยแพร่ → Average Views ตามวัน

ขั้นตอนคำนวณใช้วันที่เผยแพร่สร้างชื่อวัน แล้วหา mean(view_count) ของแต่ละวันก่อนจัดอันดับ

01
Extract weekday index

published_date.dt.dayofweek แปลงวันที่เป็นเลข 0–6 โดย Monday = 0 และ Sunday = 6

02
Map day name

ใช้ day_map เปลี่ยนเลข 0–6 เป็น Monday, Tuesday, Wednesday … Sunday

03
Average views

groupby('day_of_week')['view_count'].mean() หายอดวิวเฉลี่ยของคลิปในแต่ละวัน

04
Rank & plot

เรียงด้วย sort_values(ascending=False) แล้วใช้ horizontal bar chart เพื่ออ่านอันดับได้ทันที

day_of_week = published_date.dt.dayofweek.map(day_map) weekly_analysis = groupby(day_of_week) → mean(view_count) → sort descending

วิธีอ่านกราฟ

แกน X และความยาวของแต่ละแท่งใช้ Average View Count จริง ของคลิปที่เผยแพร่ในวันนั้น ไม่ใช่ค่าสัดส่วนเทียบฐาน และไม่ใช่ยอดวิวรวมของวันนั้น การเรียงจากมากไปน้อยช่วยให้เห็นอันดับได้ทันที และ Filter แยก Weekday / Weekend ได้

  • Wednesday = 1,087,180.09 average views
  • Friday = 864,660.55
  • Thursday = 730,683.65
  • Saturday = 438,836.60 · ต่ำสุด

สิ่งที่กราฟบอก — และสิ่งที่ยังบอกไม่ได้

กราฟสนับสนุนว่า คลิปที่เผยแพร่วันพุธมี average views สูงที่สุดในข้อมูลที่วิเคราะห์ แต่ยังไม่พิสูจน์ว่าการเลือกวันพุธเป็นสาเหตุที่ทำให้ยอดวิวสูงขึ้น เพราะยังมีตัวแปรอื่น เช่น ปีที่เผยแพร่ อายุคลิป ประเภทเนื้อหา และพฤติกรรมการฟังสด

Observed: Wednesday has the highest average views. Not proven: Publishing on Wednesday causes higher views.
